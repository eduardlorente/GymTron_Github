# Frontend Documentation

This hub owns presentation-specific evidence for the supported GymTron frontends.

| Guide | Belongs here | Does not belong here |
|---|---|---|
| `maui.md` | `GymTron.App` pages, XAML, view models, App services, navigation, binding, lifecycle, and UI composition | Persistence implementation or cross-project dependency rules |
| `web.md` | `GymTron.Web` Razor Pages, page models, Web view models, binding, validation, and presentation error handling | Application handler policy, database implementation, or delivery operations |

Cross-layer structure belongs in `docs/architecture/design.md`. C# conventions belong in `docs/language/csharp.md`. Missing capabilities belong only in `docs/requirements/technical-requirements.md`.
